## Зачем это нужно

Большинство todo-приложений теряют вашу работу. Переключили вкладку — черновик исчез. Ошиблись — отменить нельзя. Удалили заметку в одной вкладке — другая сломалась.

Todo Notes решает эти три проблемы через клиентскую архитектуру, которая уважает ваши данные — даже когда что-то идёт не так.

## Возможности

- **Undo/redo, который помнит** — история из 50 шагов. Непрерывный ввод текста считается одним действием. Ctrl+Z / Ctrl+Shift+Z на странице редактирования.
- **Черновики переживают сбои** — автосохранение каждую секунду в localStorage. Вернитесь завтра — восстановите работу.
- **Безопасно во вкладках** — удалили заметку в другой вкладке? Модальное окно расскажет что случилось. Нет сломанного интерфейса, нет тихой потери данных.
- **Без UI-библиотек** — каждый компонент создан с нуля на SCSS. Полный контроль над стилями и поведением.
- **49 unit-тестов** — логика истории, Pinia-стор и утилиты localStorage покрыты Vitest.

## Использование

Создайте заметку, добавьте задачи, используйте Ctrl+Z для отмены ошибок:

```
/                  → Список всех заметок
/note/new          → Создать новую заметку
/note/:id          → Редактировать заметку
```

Горячие клавиши на странице редактирования:
- `Ctrl+Z` — Отменить
- `Ctrl+Shift+Z` или `Ctrl+Y` — Повторить

## Архитектура

```
app/
├── pages/              # Компоненты маршрутов
│   ├── index.vue       # Список заметок
│   └── note/[id].vue   # Редактор (228 строк)
├── components/
│   ├── app/            # Переиспользуемые: Button, Input, Modal
│   └── note/           # Фича: Card, TodoItem, действия
├── composables/
│   └── useHistory.ts   # Движок undo/redo (чистые функции + composable)
├── stores/
│   └── notes.ts        # Pinia: CRUD, синхронизация с localStorage
├── types/
│   └── index.ts        # NoteLayoutState, TodoItem, HistoryDelta
└── utils/
    └── storage.ts      # Утилиты localStorage с версионированием схемы
```

<summary>Сравнение с альтернативами</summary>

| Возможность | Todo Notes | Приложения только с localStorage | Приложения с сервером |
|-------------|-----------|--------------------------------|---------------------|
| Undo/redo | 50 шагов, учитывает blur | Нет | Редко |
| Восстановление черновика | Автосохранение + запрос | Вручную | Требует бэкенд |
| Безопасность вкладок | Модальное уведомление | Крэш или тихая потеря | WebSocket-синхронизация |
| Offline-first | Да | Да | Нет |
| Деплой | Статика (Docker/GH Pages) | Статика | Требует сервер |
