# Todo Notes — SPA-приложение для заметок

Nuxt 4 SPA с двухстраничной архитектурой: список заметок и редактирование с undo/redo.

## Технологии

- Nuxt 4 (SPA, Composition API, TypeScript strict)
- Pinia (state management)
- SCSS/SASS (собственная вёрстка, без UI-библиотек)
- Vitest (unit-тесты)
- Docker / docker-compose

## Запуск

### Через Docker (рекомендуется)

```bash
docker-compose up
```

Приложение доступно на `http://localhost:3000`.

### Через pnpm (разработка)

```bash
pnpm install
pnpm dev
```

### Сборка и превью

```bash
pnpm build
pnpm preview
```

### Тесты

```bash
pnpm test
```

## Архитектура

### Страницы

| Маршрут | Описание |
|---|---|
| `/` | Главная — список всех заметок (заголовок + превью Todo) |
| `/note/new` | Создание новой заметки |
| `/note/:id` | Редактирование существующей заметки |

### Компоненты

| Компонент | Назначение |
|---|---|
| `AppModal` | Универсальное модальное окно (focus-trap, Escape) |
| `ConfirmModal` | Диалог подтверждения действия |
| `NoteCard` | Карточка заметки на главной странице |
| `TodoItem` | Пункт списка задач на странице редактирования |

### Composables

| Composable | Назначение |
|---|---|
| `useHistory` | Undo/redo: стек действий (макс. 50), применяет/откатывает изменения |
| `useStorage` | Синхронизация с localStorage, черновик, версия схемы |

### Store (Pinia)

`useNotesStore` — CRUD заметок, состояние редактирования, загрузка/сохранение.

## Ключевые фичи

- **Undo/Redo** — история из 50 записей; непрерывный ввод текста = одна запись (фиксация по blur/паузе); Ctrl+Z / Shift+Ctrl+Z глобально на странице редактирования.
- **Черновик** — незавершённое редактирование переживает перезагрузку; при возврате пользователю предлагается восстановить.
- **Версия схемы** — данные в localStorage содержат `version` для совместимости при обновлениях.
- **Подтверждения** — удаление, отмена редактирования — через модальные окна (не alert).
- **Edge-cases** — прямой переход по URL несуществующей заметки → редирект; удаление заметки во второй вкладке → приложение не ломается.
